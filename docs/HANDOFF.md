# Handoff: D&D 5e (2014) player companion

For whoever (a new Claude conversation) picks this up. Read this, docs/NOT-TRACKED.md and README.md's roadmap table first.

## The project
- Giorgos's table companion PWA. Repo: github.com/Moukoulou-glitch/dnd-companion (push to `main`; CI builds and deploys).
- Principles: **warn, never block**; **every number has a breakdown**; 2014 rules.
- Standing rules from Giorgos:
  - Feats he remastered stay remastered (content/packs/table-2014/feats-remastered.json).
  - No third-party content (Grim Hollow etc.). **No Artificer at all.**
  - House rules: Polymorph limited by the caster's CR/level; flanking gives advantage; Sharpshooter works with thrown Psychic Blades.
  - Importing his own feats/features/spells: later, not now.
  - He writes in English in this project; prefers directness and honest pushback.
- **Copyright**: no non-SRD book text in the repo. SRD 5.1 text (CC-BY) is fine. Everything else is summarized in our own words. His book files load on his device only (IndexedDB) and attach text by name.

## Layout
- packages/schema (zod: content.ts, character.ts, operations.ts, modifiers.ts)
- packages/engine (derive.ts = the sheet; shapes.ts = forms, summons, creature stat blocks, damage defenses; turn.ts; books/ = book-text import; registry.ts = packs, class merge with `adds`)
- packages/store (apply.ts = every operation; CharacterLog replays ops, so ids must be deterministic: use `op.id`, never Date.now())
- packages/dice (composeD20/composeDamage; suggestions can swap the weapon die with `weaponDice`)
- packages/app (React/Vite; App.tsx holds the flows; components/*)
- content/packs/srd-5.1 (generated by scripts/import-srd-classes.py and build-srd-spells.py; patch both the script and the JSON)
- content/packs/table-2014 (the table's own pack: one id per pack; class overrides use `features` to replace a level, `adds` to add without replacing; subclasses-<class>.json hold all PHB/XGtE/TCoE subclasses)

## How to work
- Check: `npx tsc -b && npx tsc -p packages/app && npm test`, then `npm run build -w @dnd/app`.
- Browser check: Playwright (Python) in the scratchpad, against `cd packages/app && setsid -f npx vite preview --port 4173 > preview.log 2>&1 < /dev/null`. Never `pkill -f "vite preview"`. A test character file must be wrapped as `{"format":"table-companion/character@1","character":{...}}` to import.
- Commit message ends with the Co-Authored-By / Claude-Session lines; `git push -q origin main`; verify with `gh api repos/Moukoulou-glitch/dnd-companion/actions/runs --jq '.workflow_runs[0] | [.head_sha[0:7], .status, .conclusion] | @tsv'`.
- Add a README roadmap row for each round; add tests (packages/store/test/phaseN.test.ts).
